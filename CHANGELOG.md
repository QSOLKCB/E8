# Changelog

## 1.0.0 — E8 Geometry Laboratory

- Added exact generation of all 240 E8 roots in doubled-integer coordinates.
- Added the 6,720-edge root graph and exact `112 + 128` family split.
- Added an order-30 Coxeter construction with eight 30-root projection rings.
- Added exponent-7 display depth and a D4 × D4 block receiver.
- Added the embedded order-three triality partition `12 + 76×3`.
- Added the exact ETQ-101 selector, selected graph and degree potential.
- Added structural filtering, palettes, root inspection, triality stepping,
  camera controls, PNG capture and state import/export.
- Added ETQ-101 basis, triality, Coxeter, graph and ETQ-303 traversals.
- Added Web Audio playback and deterministic 48 kHz stereo WAV export.
- Added a receiver manifest that keeps canonical symbolic note identity
  separate from tuning, timing, timbre and PCM choices.
- Added dependency-free smoke tests, CI and GitHub Pages deployment.
